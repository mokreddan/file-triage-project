COMP H2702 - File Triage Project Dataset

All files in this package are SAFE, SYNTHETIC teaching samples.
They are not malware and contain no executable code.

Suggested analysis:
- filename
- file size
- extension
- last-modified time
- SHA-256 hash
- whether the hash matches hashes_reference.csv
- a clear status such as KNOWN / UNKNOWN
- export a summary report to TXT, CSV or JSON

Important observations:
- Two files may have different names but identical contents.
- A very small change in a file can produce a completely different hash.
- Do not upload any file to external services unless your lecturer explicitly allows it.

Recommended project extension:
Process all files in the folder automatically instead of analysing one file at a time.
